🚀 Explanation: python -m venv venv
This command is used to create a virtual environment in Python. Let’s break it down:

1️⃣ What is a Virtual Environment?
A virtual environment (venv) is an isolated workspace that allows you to install Python packages only for a specific project, without affecting the global system Python installation.

This is useful because:
✅ It prevents conflicts between different projects.
✅ It allows different projects to use different versions of the same package.
✅ It keeps your system clean by avoiding unnecessary installations globally.

2️⃣ Breaking Down the Command:
python -m venv venv
python → Calls Python.

-m venv → Uses the venv module (built into Python) to create a virtual environment.

venv → This is the name of the virtual environment folder that will be created inside your project.

After running this command, a new folder named venv/ is created in your project directory. It contains:

📂 venv/
├── Scripts/ (or bin/ on Mac/Linux) → Stores activation/deactivation scripts.
├── Lib/ → Contains installed Python libraries.
├── pyvenv.cfg → Configuration file for the virtual environment.

3️⃣ How to Activate the Virtual Environment?
Once the venv/ folder is created, you must activate the virtual environment before installing packages.

Windows (PowerShell):
venv\Scripts\activate

Mac/Linux (Terminal):
source venv/bin/activate

After activation, you’ll see (venv) in the terminal, indicating that the virtual environment is active.

4️⃣ How to Deactivate the Virtual Environment?

To exit the virtual environment, simply run:
deactivate

✅ Summary:

-python -m venv venv creates an isolated Python environment.
-The venv/ folder contains dependencies specific to your project.
-You must activate the virtual environment before installing packages.
-Use deactivate to exit the virtual environment.
