## 1️⃣ Definition of Flask-SQLAlchemy
Flask-SQLAlchemy is an extension for Flask that integrates SQLAlchemy, a powerful Object Relational Mapper (ORM). 
It allows you to interact with databases using Python instead of raw SQL queries.

## Explanation

Flask-SQLAlchemy needs to know where and how to connect to a database. This is done using the 
`SQLALCHEMY_DATABASE_URI` configuration key. The value of this key is a database URL, which follows this format:

# Format:
dialect+driver://username:password@host:port/database_name

- **dialect** → Type of database (e.g., `sqlite`, `postgresql`, `mysql`, `mariadb`)
- **driver** → *(Optional)* The driver used to connect (e.g., `psycopg2` for PostgreSQL)
- **username** → Database username
- **password** → Database password
- **host** → Database server address (e.g., `localhost`, `127.0.0.1`)
- **port** → Database port (e.g., `5432` for PostgreSQL, `3306` for MySQL)
- **database_name** → The name of the database

---

## Examples

### 1. Using SQLite (Local File Database)

app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///mydatabase.db'

- Uses SQLite as the database.
- `sqlite:///mydatabase.db` means it will store data in a file called `mydatabase.db` in the project directory.
---

### 2. Using PostgreSQL

```python
app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql+psycopg2://user:password@localhost:5432/mydatabase'
```
- Uses PostgreSQL as the database.
- `psycopg2` is the driver for PostgreSQL.
- `user:password` → Replace with actual database credentials.
- `localhost:5432` → The database is running locally on port `5432`.
- `mydatabase` → The name of the database.

---

### 3. Using MySQL

```python
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://root:password@localhost:3306/mydatabase'
```
- Uses MySQL as the database.
- `pymysql` is the driver for MySQL.
- `root:password` → Replace with actual database credentials.
- `localhost:3306` → The database is running locally on port `3306`.
- `mydatabase` → The name of the database.

---

## Why is `SQLALCHEMY_DATABASE_URI` Important?

- It tells Flask-SQLAlchemy where to find the database.
- It allows Flask to connect to different databases by simply changing the connection string.
- It enables ORM (Object Relational Mapping) so we can interact with the database using Python instead of raw SQL queries.



## 2️⃣ Installation Steps

### Step 1: Install PostgreSQL
First, ensure you have PostgreSQL installed. Download and install it from:
🔗 [PostgreSQL Official Site](https://www.postgresql.org/download/)

During installation, remember the username, password, and port number (default is 5432).

### Step 2: Install Flask-SQLAlchemy
Now, install the necessary Python packages:

```bash
pip install flask flask-sqlalchemy psycopg2
```
✅ `flask` → Required for building Flask applications  
✅ `flask-sqlalchemy` → ORM for Flask  
✅ `psycopg2` → PostgreSQL driver to connect Flask with PostgreSQL  

---

## 3️⃣ Setting Up Flask-SQLAlchemy

### Step 1: Create a Flask App
Create a new file, `app.py`, and add this basic setup:

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

# PostgreSQL Database Configuration
app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql://username:password@localhost:5432/database_name'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False  # To suppress warning messages

db = SQLAlchemy(app)  # Initialize database connection

@app.route('/')
def home():
    return "Flask with PostgreSQL is set up!"

if __name__ == '__main__':
    app.run(debug=True)
```

---

## 4️⃣ Explanation of the Code

✅ `app.config['SQLALCHEMY_DATABASE_URI']` → Defines the database connection string.  
🔹 Format: `'postgresql://username:password@localhost:5432/database_name'`  
🔹 Replace `username`, `password`, and `database_name` with your PostgreSQL details.  

✅ `db = SQLAlchemy(app)` → Initializes the database connection.  

✅ `@app.route('/')` → Defines a basic route to test if Flask is running.  

✅ `app.run(debug=True)` → Runs the Flask app in debug mode.  

---

## 5️⃣ Running the Flask App

### 1️⃣ Start PostgreSQL (Ensure it’s running).  
### 2️⃣ Run the Flask app:

```bash
python app.py
```

### 3️⃣ Open a browser and go to [http://127.0.0.1:5000/](http://127.0.0.1:5000/)  
✅ If everything is set up correctly, you should see:  
🚀 "Flask with PostgreSQL is set up!"
